# Amplitude Data Extraction

- Connecting to the Amplitude API
- Extracting zip file received
- Iterating through subsequent gzip files to extract
- Saving output data locally.


### Dependencies

- [requirements.txt](https://github.com/JadenMatt/DES8-Amplitude/blob/main/requirements.txt)

- Amplitude API credentials
  - Format .env file with:
      - AMP_API_KEY = 'xxx'
      - AMP_SECRET_KEY = 'xxx'
